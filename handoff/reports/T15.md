## Decisions

1. **Không dùng task group cho cặp browser/callback** (TECH §7 bước 4 gợi ý group): khi A (browser) throw, group cancel B đang treo trên `CheckedContinuation` của `waitForCallback` — continuation không tự resume khi task bị cancel → group chờ vô hạn (deadlock). Thay bằng: callbackTask unstructured + trình tự browser-present → await callbackTask.value; `receiver.stop()` (mọi đường thoát) resume continuation nên không task nào treo. U42/U43 vẫn chứng minh đúng ngữ nghĩa.
2. iss template Microsoft ở bước callback: so pattern `{tenantid}` → `[^/]+` (chưa có tid); id_token mới so chính xác theo tid (T14).
3. Bồi hoàn: sau khi tạo secret, mọi lỗi → `try? secrets.delete` rồi rethrow (không che lỗi gốc).
4. Test dùng `BrowserEchoReceiver` (lấy state thật từ authorize URL mà fake browser mở — mô phỏng state đi qua trình duyệt; login nhiều lần tiêu thụ URL theo thứ tự).

## Deviations

- Cấu trúc chạy đua browser × callback khác TECH §7 bước 4 (group → unstructured task) vì deadlock nêu trên; ngữ nghĩa giữ nguyên (browser return bình thường không kết thúc luồng — U43).
