# Keyloft

Token/secret vault cho macOS. Giai đoạn 1: OAuth core (Google, Microsoft, Dropbox).

- Build: `make build` · Test: `make test` · Lint: `make lint` (chi tiết: `AGENTS.md`).
- Test Keychain thật (chạy tay, chạm login Keychain): `make test-keychain`.
- Spec: `docs/PROJECT-SPEC.md`, `specs/`; tiến độ task: `handoff/BOARD.md`.
